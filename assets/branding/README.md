# Retired BlueEngine artwork

The user retired the white rat on the blue tile on 2026-10-19. Do not reuse this
image in title screens, icons, logos, new projects or other artwork unless explicitly
requested again. This supersedes earlier approval of it as default branding.
The BlueEngine Games studio card uses centered text without an image.

- `blueengine.ico`: historical multi-resolution Windows icon.
- `blueengine.png`: matching historical PNG.

These files and legacy copies in scripts/ remain for compatibility. They are not
bundled with new Feta releases or displayed by the Feta client.
